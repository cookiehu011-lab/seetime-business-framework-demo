# 实施计划：个人版相机挂载工作台

1. 为相机挂载分步状态与 POI 固定目标写回归检查；确认原实现缺少“核对/选择/确认”内容隔离，并复现 POI 入口地图点击丢上下文。验证：失败检查能够定位旧行为。
2. 调整工作区渲染：队列/POI 首页、核对、选择、确认、完成；沿用现有相机数据和 POI picker。验证：每步出现正确的内容与操作。
3. 调整事件状态：前进/返回、固定目标地图 marker、显式保存与完成回流。验证：入口上下文、地图预览和已挂载结果一致。
4. 调整 CSS 响应式与视觉层级。验证：桌面/窄屏下地图、工作区、操作栏不遮挡。
5. 执行静态检查与浏览器走查，修复后重复验收。验证：本 spec 的六项验收标准全部通过。
6. 核对 diff 与仓库状态，提交并推送 `main`。验证：本地 HEAD 与 `origin/main` 一致。
