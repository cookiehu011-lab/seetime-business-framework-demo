# 分析配置平台接入

目标：复用已确认的独立配置交互，平台级管理个人版/治理版提示词；保留个人版静态标签数据。

假设：继续本地演示，无真实模型调用或后端发布。当前 origin 的旧提示词可复制迁移，原 file URL 或其他域名数据不自动转移。

步骤与验证：
1. 将原配置模块同源嵌入，隐藏重复外壳；新增平台分析配置路由，旧提示词入口改为跳转。验证权限、项目无关访问与个人标签入口。
2. 复制迁移旧提示词（版本/草稿/日志），保留旧数据；验证幂等与标签不变。
3. 接入未保存离开保护，侧栏折叠不重建 iframe；验证取消/确认离开及 Tab、编辑展开、保存、试跑、发布、回滚。
4. Node 回归、Chromium 宽窄屏与无脚本错误验证，提交并推送 GitHub。

D-001 接入方式（L2）
候选 A：同源嵌入原模块；B：全部重写为父 DOM 组件。
前端、产品、数据/测试三位独立评审均投 A（3:0）。
收益：隔离全局样式、state/render、事件，保留已确认交互，范围更小。
反方挑战：iframe 被父 render 重建时可能丢草稿，重复管理入口会造成数据歧义。
决议：A；父级捕获离开操作，调用模块草稿确认；旧提示词入口跳转新模块，复制迁移旧版本，标签仍沿用原来源。
风险：Low，已保存配置仅本机浏览器，不代表真实后端生效。
Owner 重点复核：平台级入口、编辑/发布交互、个人版标签归属。

验收结果：76 项 Node 测试通过；Chromium 验证平台入口、两应用页签、新建提示词、试跑发布、回滚、取消/确认离开、侧栏折叠保留草稿、旧入口跳转、刷新恢复、编辑展开/Esc、存储失败提示与保护、390px 窄屏。无页面脚本错误。
代码复查发现账号菜单误触发离开确认，已收窄至路由与身份切换。
遗留限制：真实模型和后端未接入；迁移限同源浏览器数据。原配置无任务字段，旧提示词按个人版相机单次观测导入。
