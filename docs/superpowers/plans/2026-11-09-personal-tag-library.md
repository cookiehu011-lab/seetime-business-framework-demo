# 个人版标签库整合

来源：聊天 01a16d9e-89f1-7442-b079-a6c0b7c80ba7 的 SeeTime分析配置Demo/SeeTime分析配置.html。

保留现有平台外壳，将 personalAnalysisConfig 入口升级为个人版标签库；复用已有分析配置 iframe，按参数打开对应页，保留提示词迁移与离开保护。

支持名称/分类/状态筛选、分页、新增/连续新增、编辑、启停、未引用删除、分类新增/重命名/移除。旧标签首次导入统一存储；停用标签不再进入相机候选词库，历史相机记录保留原标签。改名追踪旧名称引用以保持删除保护。

引用次数来自当前浏览器已授权项目的示例相机与本地保存档案，非生产统计。所有设置保存在当前浏览器，不具备跨用户同步。

UX：暗色、筛选栏和列表分区、固定表头、可滚动表体、分页、右侧操作、居中弹窗；保存失败保留弹窗并回滚内存修改。
