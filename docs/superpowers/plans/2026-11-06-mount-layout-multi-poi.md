# 挂载工作区布局、多选与手工 POI

范围：减少左右留白；首页默认目录+地图；按需展开队列/POI工作区；POI多选；无搜索结果时地图选点新增；常驻底部图例；右上 AI/人工治理筛选。

假设与局部决策：
- 治理筛选沿用已有个人信息治理状态（已治理、待治理、无需治理），两个条件取交集。
- 多选新增关系，保留其他已有关系；重新挂载只替换当前原关系一次。
- 手工选点为 GCJ-02；名称必填，类型和文字位置选填。新建 POI 加入已选集合，挂载仍需单独确认。
- 电脑使用完整可用宽度；平板/手机将地图和工作区纵向排列。
- 沿用本地示例存储，不新增后端、服务密钥或真实地图服务授权。

执行与验收：
- 87 项 Node 测试通过，包含多选、AI预挂审核一次、保存回退、手工坐标、治理条件交集。
- Chromium 验证首页无默认右面板、POI展开关闭、多选保存2个POI、地图实际点击选点并新增保存、空选填字段。
- 1600px、1000px、390px 布局核查；平板/手机地图与详情不叠加，无页面横向溢出。
- 修复实测发现：默认POI首次点击、加载遮罩挡控件、选点时标记导航抢占、窄屏控件遮挡详情。
- 交叉代码审查修复：新建POI清除旧拒绝状态、无法挂载取消恢复多选、治理筛选同步下一台队列。

限制：名称模糊搜索仍依赖此前配置的高德服务；本次未新增授权。地图底图瓦片加载受现有外部服务影响，实际点击坐标与本地保存流程已验证。
