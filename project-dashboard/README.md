# 项目运营看板集成

入口：项目池 → 杭州市公共空间项目 → 项目运营看板。

基于 `demos/project-operations-dashboard-ux-review`（2026-11-09）原型，原始文件保持不变。平台同源嵌入，隐藏重复导航。独立120台模拟样本仅供杭州公共空间项目体验，不对应平台基础相机清单，不连接真实监测。其他项目明确显示未配置样本。真实统计仍需要确认产品设计 Q1—Q5 和数据接口。

数据时间固定为 2026-11-09 10:40（北京时间）；刷新不会改变模拟快照。模块业务入口仅携带平台当前项目，不携带模拟相机 ID。

- `node project-dashboard/tests/metrics.test.cjs`：54项统计断言。
- `node project-dashboard/tests/time-scope.test.cjs`：时间范围、加权汇总、当前状态隔离。
- `node --test tests/*.test.cjs`：平台回归。
- 浏览器：来源查询、未应用提示、周期及非法日期、明细返回、跨模块返回保留筛选、侧栏收起、空数据、失败重试、项目切换、角色授权入口、无权限阻断。
- 布局：1920、1440、1366、805、390宽度。
